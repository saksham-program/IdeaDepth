## 🎨 Customization Quick Tips

### Change Colors
Edit `tailwind.config.js`:
```javascript
colors: {
  accent: {
    blue: '#3b82f6',  // Your color here
    teal: '#14b8a6',  // Your color here
  },
}
```

### Modify Landing Text
Edit `src/components/screens/LandingScreen.tsx`:
```tsx
<h2>Your custom headline</h2>
```

### Add Input Placeholders
Edit `src/components/screens/InputScreen.tsx`:
```typescript
const PLACEHOLDER_EXAMPLES = [
  "Your example...",
];
```

### Adjust Analysis Logic
Edit `src/lib/analysisEngine.ts`:
- Domain detection logic
- Assumption generation
- Consequence mapping
