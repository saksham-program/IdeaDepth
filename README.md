# 🚀 IdeaDepth — Think Before You Decide

> **“Good decisions aren’t made fast. They’re made deep.”**

IdeaDepth is a structured decision-analysis web app that helps users break down important life, career, startup, and education decisions using clear logic, reality checks, and conditional recommendations — not generic chatbot advice.

This project focuses on **thinking quality**, not just answers.

---

## 🌟 Why IdeaDepth?

Most tools jump straight to conclusions. IdeaDepth forces clarity first.

- ✅ Structured reasoning (not chat spam)
- ✅ Context-aware analysis
- ✅ Domain-specific logic (career ≠ startup ≠ education)
- ✅ Conditional recommendations (no single “right” answer)
- ✅ Honest uncertainty disclosure
- ✅ Clean, modern UI built for real users

---

## 🧠 What This App Does

Users:
1. Enter a real decision they’re stuck on  
2. Provide context (risk tolerance, timeline, experience level)  
3. Receive a **7-section structured analysis**, including:
   - Understanding the situation
   - Hidden assumptions
   - Reality checks
   - Consequences & trade-offs
   - Alternatives
   - Conditional recommendations
   - Known vs unknown factors  

No shortcuts. No motivational fluff. Only **better thinking**.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (React 18)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** React Context
- **Architecture:** Screen-based, component-driven flow
- **Deployment Ready:** Netlify / Vercel

---

## 📸 Application Flow

```

Landing → Input → Thinking → Analysis → Refinement

```

Each screen is designed to reduce cognitive overload and build trust step-by-step.

## 🧪 Analysis Engine

- Deterministic and context-aware
- No API dependency in current version
- Clean separation between logic and UI
- LLM integration scaffold already included

Designed so the reasoning layer can be swapped with any LLM later without rewriting the UI.
